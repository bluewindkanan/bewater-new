### Original intent

- **User's own words:**
  - "我要做个创始人 IP 短视频的 agent"
  - "AI 应该帮他把那些程序化的事情给做完，尽可能让他去选择"
  - "它应该是个放大器"
  - "AI 是有临界点的……这就是触发了一直以来的痛点"
  - "抱怨主要还是费时间，但是没流量"
- **Trigger / why now:** 创始人做 IP 短视频"费时间 + 费钱"的痛点一直存在；产品作者判断 AI 能力刚好越过临界点，程序化工序（选题素材、文案、粗剪、发布运营动作）首次可以被大规模自动化到"人只做选择"的程度。
- **Desired change:** 中小企业老板从"费时费钱、产出粗糙、大多数没流量"变为"每天约 30 分钟工具互动，产出专业级内容并开始有流量"。

### Project definition

- **Challenge:** 中小企业老板做创始人 IP 短视频面临三重困境：全部自己干则粗糙且耗时（剪辑最费时间）；找代运营则成本高、而且照样占用创始人时间；多数人"想起来做一下，完全不专业，随便发发"，自然没流量。时间与金钱投入高而流量回报不确定。AI 过临界点后程序化工序可被自动化，但"选得更准 / 更有流量"依赖方法论——如何以放大器模式（AI 干程序化 + 人做选择）把创始人的时间成本压到每天约 30 分钟并改善流量结果，尚未验证。
- **Intent and outcome:** 产品作者（代运营老兵 + IP 创作者）为粗糙自干派中小企业老板构建一个创始人 IP 短视频全流程 copilot：选题 / 文案 / 剪辑 / 运营四环节，AI 完成程序化工序、人做关键选择；方法论以自有经验起步、向账号数据闭环演进。期望结果 = 单条视频的创始人时间成本降到每天约 30 分钟工具互动，内容质量与流量结果被放大。
- **Target and situation:** 首发：粗糙自干派——中小团队企业老板，已全部自己在做（或认真想做）创始人 IP 短视频，愿意投入时间但产出粗糙，抱怨费时间 + 没流量；欲望是少时少钱做出专业、开始有流量的内容。观察到的另外两派（非首发）：代运营派（稍有钱，成本高且仍费时间）、随便发发派（人数最多但零习惯零预算，与放大器定位冲突——没有可放大的内容判断）。
- **Current behavior and alternatives:**

  | 流派 | 现状做法 | 代价 |
  |---|---|---|
  | 粗糙自干派 | 全部自己干 | 省钱，但质感差、耗时（剪辑最重） |
  | 代运营派 | 稍有钱的找代运营外包 | 成本高，而且照样费时间（沟通 / 出镜 / 返工） |
  | 随便发发派（大多数） | 想起来才发，完全不专业 | 零连续性，自然没流量 |

- **Provisional solution hypothesis:** 四环节 copilot / agent——选题（推荐与筛选辅助，让选择更容易更准）、文案（生成与改写，向"更有流量"的写法优化）、剪辑（基于批量拍摄素材的自动化粗剪到成片）、运营（发布与复盘动作辅助）；AI 做程序化的事，人在每环节拍板；以订阅制 SaaS 交付。注意：这是用户当前的解决设想，不是已验证的方向。
- **Scope:**
  - Included：四环节 copilot（选题 / 文案 / 剪辑 / 运营）；首发主平台 = 微信视频号（产品作者的 IP 主阵地）；以每周批量拍摄的真人素材为输入；支持日更节奏。
  - Excluded：全托管、无人参与选择的服务模式（与产品哲学冲突）；代运营式人工服务包；数字人替代真人出镜（与创始人 IP 的真人信任属性冲突，暂排除）；多平台矩阵管理（首发不锁定）。
  - First-cycle boundary：产品作者自有 IP 的 dogfood——在自己账号上验证"日更 × 单条工具互动 ≤30 分钟"。
- **Constraints:** 起步资源以产品作者个人时间与自有方法论为主；AI 剪辑的质感天花板未知；平台规则与接口能力存在外部限制；真人出镜不可省略（以每周批量拍摄在环外解决，与每天 30 分钟的预算自洽）。
- **Success definition:** 首个成功信号（user-selected）：产品作者自己的 IP 做到日更、单条视频的工具互动时间 ≤30 分钟。中期信号：粗糙自干派用户持续订阅使用，且其内容开始出现可观察的流量改善。流量是结果指标与观察对象，不构成服务承诺。

### Money + Magic

- **Magic / consumer value proposition:** 在"老板没时间、没团队、没方法论"的情境里，把做一条专业级创始人 IP 短视频的成本压到每天约 30 分钟的选择题：AI 干程序化工序，人的内容判断被放大而非被替代。
- **Magic / consumer target:** 粗糙自干派中小企业老板：已经在自己干、被费时间和没流量双重折磨、想要专业结果但不愿回到代运营模式的人。
- **Money / commercial value proposition:** 订阅制 SaaS（按月付费的自助工具）；早期以自有 IP dogfood 验证价值主张并喂养数据闭环，后续向目标人群开放订阅。付费意愿与价位为显式 Unknown。
- **Money / leverageable assets:** 产品作者的代运营老兵经验 + 自有 IP 实操体感（方法论的初始来源）；自有账号（数据闭环的第一批数据源与 dogfood 场地）；对三流派痛点的 firsthand 观察。
- **Tension and balance:** ① 放大器不承诺流量，但订阅续费靠流量结果——Magic 与 Money 在"结果责任边界"上相互约束，balance_choice 取"省时间 + 放大判断"立产品、流量作结果观察；② "让他选择"与"选择即时间"的矛盾留在 Tensions 持续观察。
