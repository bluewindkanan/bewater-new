# Immersion stage

Immersion turns the user's current project intent into a confirmed-expression Charter, active root
assumptions, and an optional source-bounded advisory report. None is a validation or Gate decision.

## Formal Discover handoff

The formal Discover inputs are the selected branch's current Charter revision plus at least three
active root assumptions. The handoff is a read-only status view, not a separate artifact.
In shorthand, the formal input is **Charter + active root assumptions**.

The Initial Assessment is advisory. It is current only when its exact input snapshot matches those
formal inputs on the same branch. Missing or stale advice does not remove otherwise complete formal
inputs and does not become a hard gate when the user explicitly asks to continue.

## Capability routing

- **bw-project-charter** — conduct the adaptive interview, self-review the complete Charter draft,
  and automatically persist the Charter plus 3–5 root assumptions.
- **bw-initial-assessment** — in fresh context, research and append the report for the exact input
  snapshot.
- **bw-discover** — recommend by default only when the formal inputs and matching Assessment are
  current; the user still makes a separate continuation decision.

Do not author artifacts in this router, manufacture a missing report, or treat advisory claims as
Fact, Evidence, Accepted Belief, or formal Insight.
