## 3. 量级目标输出

数据回收后，由 Discover agent 协助算出以下量级：

### 3.1 单台 AI 眼镜年推理成本（按 ERNIE 4.0 Turbo）

输入假设（基于 M4 现有证据）：
- 单台设备日均调用：20 次
- 单次平均 input：1000 tokens；output：500 tokens
- 多模态占比：30%（按 D-003 倍数加权）

计算：
```
单台日成本 = (20 × 1000 × input价 + 20 × 500 × output价) × (1 + 多模态倍数加权)
单台年成本 = 单台日成本 × 365
百万台年成本 = 单台年成本 × 1,000,000
```

### 3.2 百度可承受 OEM 报价下限

```
报价下限 = 单位成本 × (1 + 最低毛利率阈值)
最低毛利率阈值 = 内部财务目标（需 D-004 + D-007 推算）
```

### 3.3 与友商对照下的价格战底线

基于 M1 友商刊例价 + D-009 单位成本差异：
- 若百度单位成本比友商低 X%，则报价底线 = 友商报价 × (1 - X% × 折扣因子)

## 5. 数据脱敏与使用边界

- **内部用：** 完整数据可用于本项目的假设闭合；不外发。
- **对外用（如 G2 投资叙事）：** 仅可用聚合后的量级（如"单位成本低于友商 X%"），具体数字需 OEM 报价口径同意。
- **存档：** 原始数据存百度内部盘；本清单的回收结果结构化为 evidence record 后写入 `_bewater/evidence.yaml`，敏感字段用区间代替精确数字。

## 6. 完成判据（PT-3 关闭条件）

- 拿到 D-001~005（P0 必须 5 项全到位）
- 至少 3 项 P1 数据（D-006/007/009 优先）
- 算出 3.1/3.2/3.3 三个量级数字

  - **支持：** 当前价格-成本结构有 ≥30% 毛利缓冲，且价格回调 50% 后仍正毛利
  - **证伪：** 毛利缓冲 <10%，价格回调即亏损；或单位成本无显著规模优势

## 8. 风险与陷阱

- **数据时效性：** ERNIE 价格变动快，月度数据可能已过时；要求最新 3 个月数据。
- **成本核算口径：** 推理成本有"GPU 折旧 + 能耗 + 运维"多种口径；明确用同一口径。
- **脱敏丢失精度：** 过度脱敏可能让数据失去判断力；争取至少区间数字。
- **内部政治：** 不同部门可能有动机美化/丑化数字；交叉验证 ≥2 个独立来源。
