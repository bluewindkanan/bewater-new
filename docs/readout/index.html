项目章程

ART-001 · charter · immersion
draftr1
把 BeWater 方法论具象化为 Agent 驱动的 SaaS「hardso」，服务 AI 硬件 founder 跑完立项前战略决策段（Immersion→G2）。目标用户是凭感觉抄竞品、战略能力弱、预算紧的 AI 硬件 founder，收入路径为 B2B2C（机构为 cohort 付费）。
核心要点
  • 命题：AI agent 主导带 founder 跑完全决策段，founder 只在 gate 上做决策
  • 目标用户：AI 硬件 founder（如儿童机器人 founder），战略能力弱、没能力做市场验证
  • Magic：把「立项前先想明白」从专业咨询才买得起变成 founder 自己跑得起
  • Money：B2B2C——孵化器/加速器/VC/硬件平台为 founder cohort 付费
  • Tension：agent 产出质量若守不住 gate 严谨性，Magic 与 Money 同时崩
  • 5 条根假设 A-001~A-005：founder 真需要、卡点是能力缺、agent 可过 gate、机构愿付费、渠道能触达
先用 AI 硬件首垂直 cohort 把 G1→G2 决策段跑通、证明 agent 产出可过 gate，再谈规模化与渠道铺开。

初步评估

ART-002 · initial-assessment · immersion
draftr1
对 hardso 命题做源有界的前置评估（非 Gate、非验证）：痛点真实且与 42% 创业失败（无市场需要）数据吻合，B2B2C 渠道结构存在。最大未知不是「founder 缺方法」，而是 agent 能否为战略弱 founder 守住 gate 严谨性，以及机构是否愿为结果付费。
核心要点
  • 命题可信但关键支撑点全是 belief 非 fact，值得继续探索
  • 最大分叉：founder 是被「没能力」卡住，还是被「没意识/没意愿」卡住
  • Agent 产出质量（A-003）是 Magic 与 Money 共同的单点失败
  • B2B2C 渠道同时是 GTM 与 L4 行为证据来源（同一 pilot 验证两件事）
  • 优先方向：在一个机构 cohort 内证明 agent 产出能过 G1/G2 gate
在真实的立项决策现场，founder 究竟是被「没能力」卡住、还是被「没意识/没意愿」卡住——这一分叉决定 hardso 是工具还是教育/激励产品。

发现期研究

ART-003 · research · discover
draftr2旧 r1 已弃
Discover Sprint 1 用 14 条原子证据（创业行为/Agent 评测/平台规则/项目评估）重构了关键不确定性。capability-vs-willingness 二分被反证为多机制结构（优先级/身份/样本/硬件阶段），B2B2C 仍是候选但采购证据缺失，明确进入 synthesize 而非再做 desk research。
核心要点
  • 「能力 vs 意愿」二分不成立——至少四类机制共同决定 founder 是否验证
  • 硬件关键不是「是否先 build」，而是 build 是否仍可逆、反证能否在不可逆量产前改变方向
  • Agent 质量需分层评测（协议/状态/重复可靠性/整体采用/修复成本），不能以文档完成率代理
  • 机构愿为相邻项目投入，但补贴/入选 ≠ 使用（40% 软件 voucher 未兑换）
  • 下一步进入 synthesize；不再做公开 desk research，需现场/cohort/机构访谈
hardso 的核心不是「替 founder 填完一套方法」，而是「在不可逆投入前制造真实承诺、正确样本、反证采纳和可审计决策变化的系统」。

签署的 Insight 组合

ART-004 · insights · define
finalr2
从 ART-003 提炼并经人签署（F/P/E/T）的 4 条互补 Insight，分别覆盖 founder 行为机制、硬件可逆性边界、Agent 质量条件、机构渠道条件。Truth 判断在有显式证据缺口处保持 provisional。
4 条 Insight（互补）
  • Insight 1 · 反证权力：真正的验证是让反证有权在不可逆投入前停止、收窄或改变承诺，而非完成步骤
  • Insight 2 · 硬件可逆性：硬件最危险的不是「先做」，而是把可逆原型过早变成不可逆承诺；验证保护可逆性
  • Insight 3 · Agent 质量：Agent 真正的价值不是隐藏复杂性，而是让未完成判断、偏航与修复成本变得可见
  • Insight 4 · 渠道基础设施：机构渠道只有承接时间承诺、公开进度、人工追问与退出后果，才成为行为基础设施
反证只有拥有改变承诺的权力，才算真正的验证——这是 hardso 整条价值链的因果核心。
